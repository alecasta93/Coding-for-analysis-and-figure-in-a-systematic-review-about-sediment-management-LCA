# Reproducing the manuscript figures

This folder contains the code used to generate manuscript Figures 2–6 and Supplementary Figure S1 from the supplementary evidence workbook. Figure 1, the PRISMA flow diagram, is prepared manually and is intentionally not generated by this script.

## Input workbook

The script expects the revised supplementary workbook:

```text
../Supplementary_Data_REV2.xlsx
```

Only the following worksheets are required:

- `Article Evidence`
- `Contribution Analysis`
- `Outcome Evidence`

The script validates the required worksheets and columns before generating any output. It does not read or redistribute the source PDFs.

## Python environment

Python 3.11 or later is recommended. From this folder, create and activate a virtual environment, then install the tested dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Windows, activate the environment with:

```text
.venv\Scripts\activate
```

## Run the analysis

From the `reproducibility_code` folder:

```bash
python generate_figures.py \
  --workbook ../Supplementary_Data_REV2.xlsx \
  --output-dir generated_figures \
  --dpi 420
```

Arguments:

- `--workbook`: path to the supplementary evidence workbook; required.
- `--output-dir`: destination folder; defaults to `generated_figures`.
- `--dpi`: PNG resolution; defaults to 420 dpi.

## Outputs

Each main figure is written as both PNG and vector PDF:

- `Figure_02_Evidence_trend`
- `Figure_03_Evidence_coverage`
- `Figure_04_Methodological_practices`
- `Figure_05_Environmental_outcomes_contributors`
- `Figure_06_Circularity_modeling`
- `Figure_S1_Clustering_audit`

The output folder also contains:

- `derived_tables/`: CSV tables used to construct the figures;
- `figure_manifest.csv`: figure filenames, source-workbook name and included-study count.

Figure 1 is not created, modified or deleted by the script. This allows the manually prepared PRISMA diagram to be managed independently.

## Figure-specific conventions

- Figure 2 uses American English (`valorization`).
- Figure 4 uses American English (`normalization`).
- Figure 5 does not include explanatory footnotes beneath the panels.
- Figure 6 uses American English (`modeling`).
- Frequencies describe evidence coverage or reported study-level signals and do not represent effect magnitudes or technology rankings.

## Reproducibility notes

The analysis is deterministic and does not use random sampling. Re-running the script with the same workbook and dependency versions reproduces the underlying counts, derived tables and figure structure. Minor text-placement differences can occur across operating systems because of font rendering. The script uses DejaVu Sans, which is distributed with Matplotlib.
